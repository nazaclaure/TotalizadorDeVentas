Parte 1
1.   Cada equipo escribe entre 15 a 20 funcionalidades (slices/rebanadas) demostrables para el usuario para desarrollar el programa. Cada una de estas funcionalidades debería poder desarrollarse en menos de 10 minutos. Ninguna funcionalidad (rebanada) es solo un mockup de la Interfaz de Usuario o crear una estructura de datos o tabla. De todas las funcionalidades(rebanadas) se puede hacer un demo con entradas y salidas reales 
Manejo de Precio Neto y Validaciones Básicas
Como usuario quiero ver el precio neto base de mi compra. Entrada: Cantidad = 3, Precio = $10 → Salida: Subtotal: $30.
Como usuario quiero calcular el precio neto con cantidades y precios decimales. Entrada: Cantidad = 10, Precio = $25.50 → Salida: Subtotal: $255.00.
Quiero ver un mensaje de error si la cantidad es menor o igual a cero. Entrada: Cantidad = -5, Precio = $10 → Salida: "Error: La cantidad debe ser mayor a 0".
Quiero ver un mensaje de error si el precio es menor o igual a cero. Entrada: Cantidad = 5, Precio = -$10 → Salida: "Error: El precio debe ser mayor a 0".


Escala Incremental de Descuentos
Como usuario quiero ver 0% de descuento si la compra no alcanza los $1,000. Entrada: Subtotal = $60 → Salida: Descuento (0%): $0.
Como usuario quiero aplicar el 3% de descuento en compras desde $1,000. Entrada: Subtotal = $1,000 → Salida: Descuento (3%): $30.
Como usuario quiero aplicar el 5% de descuento en compras desde $3,000. Entrada: Subtotal = $3,000 → Salida: Descuento (5%): $150.
Como usuario quiero aplicar el 7% de descuento en compras desde $7,000. Entrada: Subtotal = $7,000 → Salida: Descuento (7%): $490.
Como usuario quiero aplicar el 10% de descuento en compras desde $10,000. Entrada: Subtotal = $10,000 → Salida: Descuento (10%): $1,000.
Como usuario quiero aplicar el 15% de descuento en compras desde $30,000. Entrada: Subtotal = $30,000 → Salida: Descuento (15%): $4,500.
Como usuario quiero ver el monto neto calculado tras restar el descuento. Entrada: Subtotal = $3,000, Descuento = $150 → Salida: Precio con descuento: $2,850.


Impuestos y Totales
Como usuario quiero ver el impuesto aplicado para el estado de Utah (UT: 6.65%). Entrada: Precio descontado = $1,000, Estado = UT → Salida: Impuesto UT: $66.50.
Como usuario quiero calcular impuestos para los demás estados (NV: 8%, TX: 6.25%, AL: 4%, CA: 8.25%). Entrada: Precio descontado = $60, Estado = TX → Salida: Impuesto TX: $3.75.
Quiero ver un mensaje de error si no selecciono un estado o introduzco un código inválido. Entrada: Estado = "XX" o "" → Salida: "Error: Seleccione un estado válido".
Como usuario quiero ver el precio total final integrando descuento e impuesto. Entrada: Subtotal = $60, Descuento = $0, Impuesto TX = $3.75 → Salida: Total: $63.75.


Formato e Interfaz
Como usuario quiero ver los montos formateados en moneda a dos decimales. Entrada: Total = 63.75 → Salida: "$63.75".
Como usuario quiero un botón para limpiar/reiniciar el formulario a cero. Entrada: Clic en "Cancelar/Limpiar" → Salida: Todos los campos de entrada y salida vacíos o en 0.
Como usuario quiero ver el resumen completo de la venta en pantalla. Entrada: Cantidad = 20, Precio = 3, Estado = TX → Salida: Renderizado completo (Subtotal: $60, Descuento: $0, Impuesto: $3.75, Total: $63.75).
